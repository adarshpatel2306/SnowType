❄️ SnowType - A Simple Typing Speed Game

SnowType is a lightweight, browser-based typing speed game that challenges users to type as many correct words as possible within a set time limit. It provides live WPM (words per minute) and accuracy tracking.

---

## 🚀 Features

- Customizable timer input (5 to 300 seconds)
- Real-time WPM and Accuracy display
- Blinking cursor and responsive design
- Keyboard event handling for a realistic typing experience
- Visual feedback for correct and incorrect keystrokes

## 🧠 How It Works

- Click **"New Game"** and optionally set a custom time.
- Start typing once the word list appears.
- The game tracks your performance live.
- Once the time is up, you'll see your final WPM and Accuracy.
